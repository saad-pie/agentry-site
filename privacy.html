Privacy Policy

Last updated: 2026-10-11 · Version 1
01 / SCOPE

Scope and System Identity

agentry is a meta-system for AI agents that maintains a capability graph, runs discovery over public sources (GitHub, the web), and proposes capability additions to a human operator. It is currently self-hosted and operated by a single individual. This policy describes what data agentry handles today, and how that will change as the system grows.

02 / WHAT WE COLLECT

Data Collection

Today: nothing from visitors to this website. No analytics, no cookies, no tracking pixels, no third-party scripts. The site is a static HTML page. For the operator of an agentry instance, agentry records operational metadata — capability gaps, discovery candidates, approval decisions — in an append-only log on the operator's own infrastructure. This log does not contain personal data of any third party.

categories: gaps, discoveries, proposals, approvals, capability_graph_nodes
03 / GOOGLE ACCOUNT ACCESS

Google Account Access

agentry's Gmail integration uses Google OAuth 2.0 with the gmail.send scope only. This scope allows agentry to send email notifications on behalf of the operator (for example, when a capability proposal is ready for approval). It does not permit reading, modifying, or deleting any email. It does not grant access to any other Google service.

scope: https://www.googleapis.com/auth/gmail.send
04 / HOW GOOGLE USER DATA IS USED

Use of Google User Data

Google user data is used exclusively to send notification emails from agentry to the operator's own address. The OAuth refresh token issued by Google is stored on the operator's own infrastructure and is never transmitted to any third party. No Google user data is processed by any external service, LLM, or analytics provider.

05 / WHAT WE DO NOT DO

Practices We Do Not Engage In

  • We do not sell data.
  • We do not share data with advertisers.
  • We do not use cookies or any client-side tracking.
  • We do not perform server-side logging of visitor IP addresses or user agents for the site.
  • We do not transmit Google user data outside the operator's own infrastructure.
06 / THIRD-PARTY SERVICES

Third-Party Services

agentry integrates with third-party services that the operator configures, currently including GitHub (for repository search), a self-hosted SearXNG instance (for open-web search), the Hugging Face platform (for hosting), and Google Gmail (for notifications). Use of those services by third parties is governed by their own policies. agentry does not share any operator data with these services beyond what is necessary for each integration to function.

07 / WHAT CHANGES AS AGENTRY GROWS

Trajectory and Growth

agentry is designed to support multiple agents, multiple capabilities, and eventually multiple operators. When a change to the system would introduce a new category of data collection, the change will be reflected in this policy — with a bumped version number and a new "Last updated" date — before that collection begins. Users who wish to be informed of changes can watch the project at github.com/saad-pie/agentry.

08 / DATA RETENTION AND DELETION

Data Retention and Deletion

Because agentry collects no third-party data, there is nothing to delete on request. Operators who wish to revoke agentry's access to a Google account can do so at any time at myaccount.google.com/permissions. To request removal of data from an agentry instance you operate, contact the address in section 09.
