03 / END-TO-END DEMO

DeepSeek Harness (DSH) End-to-End Trial

When DSH encounters an unhandled operation in production (e.g. specialized TSV/PDF processing):

  • First execution: 2m 07s (DSH analyzes gap, runs package search, calls agentry build_from_plan, trials, and adds node).
  • Repeat execution: ~15s total end-to-end (DSH checks graph, finds existing capability, invokes directly in 150ms).
04 / REPRODUCE

Reproduce with curl

You can verify warm execution latency against the live Hugging Face deployment using this exact command: 

curl -X POST https://saadpie1-deepseek-harness.hf.space/api/agentry/invoke \
  -H "Content-Type: application/json" \
  -d '{"name": "bench_tsv_v1", "args": {"input": "a\tb\n1\t2\n"}}'
